# Legacy Dashboard Export

## Notice: Not the Live Application

The files in this directory (`dashboard.html`) represent a **legacy single-file HTML distribution** generated by `build_interactive_ui.py`. It is retained solely for offline archive and standalone demonstration purposes.

### Live Application
The live, active LunaSafe / OrbisLuna platform application is located at:
- Frontend: [`web/index.html`](../web/index.html) (with modern multi-layer canvas, Web Worker calculation, and Three.js 3D studio)
- Backend: [`web_server.py`](../web_server.py) (zero-dependency stdlib HTTP server)

To launch the live application, run:
```bash
python web_server.py
```
and open `http://localhost:8050` in your browser.

### Regenerating this Legacy Artifact
If you need to regenerate `legacy/dashboard.html` from the current dataset bundle:
```bash
python build_interactive_ui.py
```
It can be viewed offline using:
```bash
view_ui.bat
```
